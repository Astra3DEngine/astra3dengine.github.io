Features

3D Viewport

Intuitive 3D viewport with perspective and orthographic modes, multi-viewport layout, and orientation cube for easy navigation.

Scene Hierarchy

Tree-structured scene hierarchy with drag-and-drop reordering, multi-selection, and context menu support.

Inspector Panel

Dynamic property inspector with transform controls, color pickers, and component-based editing.

Asset Management

Import and manage 3D models, textures, and prefabs with built-in file browser and preview support.

Export & Build

Export your games as standalone web applications or build desktop versions with Electron.

i18n Support

Multi-language support with English, Chinese, Japanese, and Russian translations built-in.

Quick Start

1

Clone Repository

git clone https://github.com/LanwyWriteXU/Astra3DEngine.git
2

Install Dependencies

cd Astra3DEngine && pnpm install
3

Start Development

pnpm run dev

Requirements

  • Node.js >= 16
  • pnpm >= 8
